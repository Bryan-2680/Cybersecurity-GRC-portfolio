### Security Monitoring Analysis – Suspicious Activity
Using SQL to query authentication and access logs for suspicious patterns, demonstrating how log analysis supports the early detection of security issues.

#### What it demonstrates

- Detection use-cases: failed-login spikes, off-hours logins, sensitive-resource access, IP concentration
- Writing and explaining SQL queries (GROUP BY, COUNT, time-window filtering)
- Interpreting results against a baseline — and judging which anomalies warrant an alert, an access review, or further context (not everything is an incident)
- Mapping to the NIST CSF Detect function and recommending SIEM-based centralised monitoring

**Key concepts:**  security monitoring, SIEM, detection use-cases, baselining/thresholds, brute-force, account lockout, SQL log analysis.

Demonstrative log-analysis exercise using illustrative sample data. Not a real production environment or SIEM platform.
